# CLI and manifest

Run `node <skill-dir>/scripts/video.mjs <command>` from the project directory, and `init <dir>` from the directory that will hold the project. `<skill-dir>` holds `SKILL.md`. `--help` prints every flag.

## Setup

- **Dependencies:** `cd <skill-dir>/scripts && bun install` once, or npm.
- **Runtime:** Node 20+. Playwright stalls under Bun 1.3, so `bun video.mjs` re-runs itself under `node`.
- **Browser, first found:** `$MOTION_VIDEO_CHROME`, then `chromium`, `chromium-browser`, `google-chrome-stable` or `google-chrome` on PATH, then Chrome or Chromium in its default macOS or Windows location, then Playwright's build (`bunx playwright install chromium-headless-shell`).
- **Also required:** `ffmpeg` and `ffprobe` on PATH. Python is not required for `check`, `sounds` or `audit`.
- **Settings:** `~/.config/motion-video/config.json` holds the model folder, the TTS engine (`tts.md`) and the speech recognition model (`narration.md`).
- **Models:** `speak` and `transcribe` first use a model on disk: the model folder, then the Hugging Face cache (`$HF_HUB_CACHE`, `$HF_HOME/hub`, `~/.cache/huggingface/hub`). Otherwise they download it once, into `$MOTION_VIDEO_MODELS`, else `"models"` in the config (`{ "models": "/path/to/models" }`), else `~/.cache/motion-video/models`. A folder you keep survives a cache clean.
- **Sound effects:** synthesized on first use into `~/.cache/motion-video/sfx/` (`$XDG_CACHE_HOME` replaces `~/.cache` when set), as `<sound>-v<variant>-<hash>.wav`. A deleted file rebuilds on the next render.
- **GPU:** Chromium draws through ANGLE (EGL on Linux, Metal on macOS, Direct3D on Windows) when WebGL reports a hardware renderer. Otherwise it draws in software. `MOTION_VIDEO_GPU=0` forces software.
- **Encoder:** `h264_nvenc` when ffmpeg can open it, else `libx264`. A failed NVENC session retries once on `libx264`. `MOTION_VIDEO_NVENC=0` forces `libx264`.

## video.json

Dotted names are nested objects: `sound.palette` is `"sound": { "palette": "wood" }`.

```json
{
  "width": 1920,
  "height": 1080,
  "fps": 30,
  "output": "out/video.mp4",
  "sound": { "palette": "wood", "key": "D major", "space": "room" },
  "scenes": [
    {
      "file": "scenes/01-hook.html",
      "duration": 3,
      "energy": [
        [0, 0.4],
        [1.2, 1]
      ],
      "in": "whoosh"
    }
  ]
}
```

| Field                              | Type                                                                                     | Default         | Rule                                                                                                                                                                                                                                                                                         |
| ---------------------------------- | ---------------------------------------------------------------------------------------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `width`, `height`                  | even integer                                                                             | 1920, 1080      | Landscape 1920x1080, portrait 1080x1920, square 1080x1080                                                                                                                                                                                                                                    |
| `fps`                              | integer 12–120                                                                           | 30              | Use 60 for fast UI motion                                                                                                                                                                                                                                                                    |
| `output`                           | path                                                                                     | `out/video.mp4` |                                                                                                                                                                                                                                                                                              |
| `sfx`                              | boolean                                                                                  | true            | Plays `data-sfx` cues. False turns off effects only, not music or voiceover.                                                                                                                                                                                                                 |
| `music.file`                       | path                                                                                     | —               | Only a track the user supplied                                                                                                                                                                                                                                                               |
| `music.volume`                     | 0–1                                                                                      | 0.25            | Before ducking and loudness normalization                                                                                                                                                                                                                                                    |
| `music.start`                      | seconds                                                                                  | 0               | Use the downbeat `beats` prints, so video time 0 is a bar start                                                                                                                                                                                                                              |
| `scenes[].file`                    | path                                                                                     | —               | Basename must be unique                                                                                                                                                                                                                                                                      |
| `scenes[].bars`                    | number                                                                                   | —               | Length in bars from `out/beats.json`. Run `beats` first.                                                                                                                                                                                                                                     |
| `scenes[].duration`                | seconds                                                                                  | —               | Used when there is no music. Set one of `bars`, `duration` or `audio`.                                                                                                                                                                                                                       |
| `voiceover`                        | path, or `{ "file", "start", "script" }`                                                 | —               | One narration for the whole video, any file ffmpeg reads. Starts at `start` video seconds (default 0). A negative `start` skips the file's first seconds. It must end within the video. `script`: its words for exact captions, as plain text, a timed script or subtitles (`.srt`, `.vtt`). |
| `scenes[].script`                  | path                                                                                     | —               | The text a scene's `audio` reads.                                                                                                                                                                                                                                                            |
| `scenes[].audio`                   | path                                                                                     | —               | Narration cut per scene. Length derives from it when `bars` and `duration` are absent.                                                                                                                                                                                                       |
| `scenes[].energy`                  | 0–1, or `[[seconds, energy], …]`                                                         | 0.6             | Planned intensity: one number, or a curve of points in scene seconds (`direction.md`, §4). | `scenes[].in`                      | `whoosh` \| `swoosh` \| `reverse` \| `riser`                                             | —               | Transition sound pre-lapped across this scene's cut. Not on the first scene.                                                                                                                                                                                                                 |
| `scenes[].inVol`, `scenes[].inDur` | number                                                                                   | 0.8, recipe     | Transition level (0–4) and length in seconds (0.2–4)                                                                                                                                                                                                                                         |
| `sound.space`                      | `tight` \| `room` \| `hall`                                                              | `room`          | The room effects sit in. Each sound sends its own share.                                                                                                                                                                                                                                     |
| `sound.fadeIn`, `sound.fadeOut`    | seconds                                                                                  | 0.3, 0.8        | Fade of the whole mix                                                                                                                                                                                                                                                                        |
| `sound.palette`                    | `synth` \| `wood` \| `glass` \| `metal` \| `plastic` \| `stone` \| `rubber` \| `ceramic` | `synth`         | The material every contact sound (`tap`, `tick`, `snap`, `thud`, `slam`) is struck in, unless a cue sets its own `data-material`. `synth` keeps the designed sounds.                                                                                                                         |
| `sound.key`                        | `auto` or a key name (`C`, `F# minor`, `Ebm`)                                            | `auto`          | The key tonal effects are tuned to. `auto` takes the key of `music`, or C major without music. `render` prints the key it used.                                                                                                                                                              |
| `sound.bed`                        | `true`, `false`, or object                                                               | none            | Echo bed under the effects. `true` takes every default. Off when absent.                                                                                                                                                                                                                     |
| `sound.bed.fragments`              | 1–8                                                                                      | 2               | Echoes per 10 s of the `data-sfx-motif` sound, else material sounds, else the most used one. Pitched down, darkened, far in a hall. They avoid hits, voice and the second before a reveal, and thin out at low energy.                                                                       |
| `sound.bed.level`                  | dB, −48 to −12                                                                           | −32             | Fragment level against an effect at volume 1. The default sits near the noise floor.                                                                                                                                                                                                         |
| `sound.bed.seed`                   | whole number                                                                             | 1               | Picks one of the seeded variations. The same seed always renders the same bed.                                                                                                                                                                                                               |

Scene boundaries round the running total to whole frames, so the video length matches the sum of scene lengths.

## Output

- **Video:** H.264 High, yuv420p, BT.709 tagged, faststart. NVENC p7 CQ 16, or libx264 slow CRF 16 with `-tune animation`.
- **Audio:** AAC 192k at 48 kHz.
- **Loudness:** −14 LUFS with voice or music, −18 LUFS for effects only, within about 0.5 LU.
  - **One linear gain** reaches the target, with no compression: relative levels stay as mixed. A peak limiter sits 0.5 dB under the ceiling: −1.5 dBTP for voice or music, −6 dBTP for effects alone.
  - **Measured on the encoded file,** since AAC rebuilds peaks between samples. The limiter runs 4x oversampled. An overshoot lowers gain and limit together.
  - **Ducking:** music ducks hard under voiceover, effects more gently. The bed ducks under every hit and word.
  - **Payoff first:** gain rises only while the loudest 400 ms keeps its lead over the rest. The lead loses at most 1.5 dB (`MOTION_VIDEO_LEAD_LOSS` overrides it). A sparse mix that cannot reach the target ships quieter, and `render` prints by how much. An effects-only mix led by one or two big hits usually ships 3–6 LU under −18 LUFS. That is not an error.
  - **Peaky loudest moment:** a sharp hit (a braam, a slam) as the loudest moment ships quieter. A sustained or tonal one ships louder. A small volume change that makes a sharp hit the loudest can drop the file several LU.
  - **Bed after gain:** the bed joins after the loudness gain, so it never lowers the foreground.
- **Bed comparison:** with a bed, `render` also writes `<output>.no-bed.mp4` at the same gain and limit. The bed has no noise layer.
